# ancestry
Content management for family history.

This is very much in development, so expect constant churn and change.

I added some sample data for Charles Dickens to give an idea of how it works. NOTE: The data is only provided to serve as an example of what the app does — it is not as complete or rigorous as i would normally prefer.
- [family group view](https://r12a.github.io/ancestry/tree?project=dickens&person=dickens_charles_john_huffam_1812)
- [detail view](https://r12a.github.io/ancestry/person?project=dickens&person=dickens_charles_john_huffam_1812)
- [ancestor view](https://r12a.github.io/ancestry/precedents?project=dickens&person=dickens_charles_john_huffam_1812)
- [descendants view](https://r12a.github.io/ancestry/descendants?project=dickens&person=dickens_charles_john_huffam_1812)

This simple content management system (CMS) uses HTML, CSS and Javascript only, so it is useable in any web browser, on any operating system.  It has also been specifically designed to work on a local machine, without server access. Apart from the fact that this makes the application useable when out in the field (such as at a graveyard) without an internet connection, this also protects privacy by removing the need to upload personal data to a server.

The whole app is designed to work, with its data, off-line, so data can be kept confidential on a hard drive or storage device.


### Notes on usage

HIGHLIGHTS IN THE PERSON PAGE IMAGE ATTACHED
﻿


➊    People page can have narratives.  These are generated by AI, and only occasionally tweaked afterwards.  The text weaves in information about societal trends, historical events, and descriptions of locations relevant to the person in question.

➋   It's possible to swap the narrative for two other things, occupying the same space.  The first is the *event list summary*: essentially a table of contents for the page.  Click on the person's age to jump to the detailed information.  This is very useful to give an overview of events in the person's life.    The second is a *set of breadcrumbs*: this is a list of events where the location is known, or where it can be guessed at based on surrounding information.  Only those events are shown.

➌   This is a list of places the person has lived, with the birth location first and the death location last.  If you click on the list you are taken to a Google Maps page that shows the location of each of these places.  Very handy to get a more concrete idea about where the person lived.

➍   The icon that looks like a network takes you to the person as they appear in the family tree in Ancestry.com (as long as you have a subscription).  This can help get a bigger pictures of the people related to that person.

➎   It's possible to tag individuals by clicking on a box at this location.  Tagged individuals show a check mark.  You can decide to tag people for any reason, but the tagging is only remembered when you use the same browser and device (though you can transfer lists of tagged people using the index page, described later).

➏   If you click on this icon then help text pops up as you mouse over various parts of the screen.  Click it again to turn that off.

➐   While entering data, it's possible to standardise the names of locations because the app suggests locations as you type. You can also append a precision marker to the end.  The case shown here indicates that the link will open Google Maps and point to the centre of the village.  In some cases the precision is exact (when you've been able to identify the actual building), sometimes it's approx (when investigation allows you to guess at an approximate location after areas have been redeveloped or are less precise), and other times the level of accuracy varies from road to registration district.



HIGHLIGHTS IN THE INDEX PAGE IMAGE

➊    The list box is down the side of the page, and always visible.  You can add lists of person ids here for a variety of uses. 

➋   This menu pops up from the square icon in the bottom right-hand corner of the page. It allows you to create and manage the lists of ids.

➌   Add check marks to two people in the main list, and then click on this icon to see how they are related.  Note that Ancestry only allows you to map paths between yourself and another person, but this function allows you to show relationships between any two people in the project.  It not only shows the people along the path when connecting the individuals, but also describes their blood relationship to the start person.
